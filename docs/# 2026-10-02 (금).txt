찾아보고 알게 된 것

- 셸 일관성의 중요성: Windows 환경에서 PowerShell 대신 `Git Bash`를 기본 터미널로 지정해야 리눅스 기반 표준 셸 명령어(`ls`, `cd`, `curl` 파라미터 등)가 오류 없이 의도대로 동작함
- 대화형 주피터 커널 구조: VS Code 내에서 노트북(`.ipynb`) 셀을 실행하려면 백엔드에서 파이썬 인터프리터와 통신하는 `ipykernel` 패키지가 사전에 설치되어 있어야 함
- 수업 파이프라인 연계: `flask`(웹훅 서버 구축) -> `requests`(HTTP 요청 발송) -> `curl`(CLI 도구 검증) -> `schedule`(배치 작업 자동화)로 이어지는 에이전트 핵심 파이프라인의 필요 패키지 의존성을 사전 파악함
