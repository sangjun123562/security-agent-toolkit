# 2026-09-29 (화)

## 오늘 새로 쓴 명령

- pwd : 현재 위치한 작업 디렉터리 경로 출력 (Print Working Directory)
- cd ~ : 홈 디렉터리로 이동
- cd .. : 한 단계 상위(부모) 폴더로 이동
- cd [폴더명] : 해당 폴더 내부로 이동
- cd ../[폴더명] : 상위 폴더를 거쳐 옆 폴더로 바로 이동 (상대경로)
- mkdir [폴더명] : 새 폴더 생성 (Make Directory)
- ls : 현재 폴더 내 파일 및 폴더 목록 확인

## 찾아보고 알게 된 것

- 폴더와 디렉터리는 같은 개념이며, 터미널 환경에서는 주로 디렉터리라고 부른다.
- 절대경로는 루트(/ 또는 C:\)부터의 전체 주소이고, 상대경로는 현재 위치를 기준으로 한 주소이다.
- 홈 디렉터리는 현재 사용자 전용 기본 폴더이며 `~` 기호로 줄여 쓴다.
- `.`은 현재 폴더, `..`은 한 칸 위(부모) 폴더를 가리킨다.
- 유닉스/Git Bash는 경로 구분자로 슬래시(`/`)를, 윈도우 탐색기는 역슬래시(`\`)를 사용한다.
- `mkdir`과 같은 명령어는 성공 시 화면에 별도 출력 없이 다음 입력 줄로 조용히 넘어간다.
- `ls` 출력 결과에서 이름 뒤에 붙는 `/`는 일반 파일이 아닌 폴더(디렉터리)임을 뜻한다.

## 막힌 것 / 주의할 점

- 터미널에서 명령어와 경로 사이에 공백을 두지 않으면 에러 발생 (예: `cd~` 입력 시 `command not found`).
- 줄 바꿈을 하려고 다른 조합키를 누를 필요 없이 명령어 입력 후 Enter를 누르면 바로 실행되며 다음 줄로 넘어간다.
- `cd ..`을 여러 번 실행하면 의도한 위치보다 더 바깥(상위)으로 나갈 수 있으므로, 길을 잃었을 때는 `cd ~`로 홈에 복귀하거나 `pwd`로 위치를 확인한다.
- 메모장에서 마크다운(.md) 파일 저장 시 파일 형식을 '모든 파일 (*.*)'로 변경하지 않으면 `2026-09-29.md.txt` 형태로 저장된다.

## 다음에 확인할 것

- 디렉터리 간 이동 시 다양한 상대경로 조합 활용법.
