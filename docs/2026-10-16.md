## 찾아본 것
서버에서 vim을 왜 사용하는가:
원격 리눅스 서버(CLI)는 마우스나 VS Code 같은 GUI 데스크톱 환경이 없기 때문에 터미널 내부에서 가볍고 빠르게 설정 파일이나 코드를 열어 편집할 수 있는 도구가 필수적이다. vim은 거의 모든 리눅스 배포판에 기본 내장되어 있어 네트워크가 끊기거나 최소 설치된 환경에서도 즉시 사용 가능하다.

## 오늘 새로 쓴 명령
vim, :w, :q, :wq, :q!, Esc, i

## vim의 세 가지 모드
1. 일반 모드 (Normal mode): 명령어를 내리는 기본 상태 (커서 이동, 줄 삭제 dd, 복사 yy 등)
2. 입력 모드 (Insert mode): 'i'를 눌러 진입하며 실제 본문 글자를 타이핑하는 상태
3. 명령줄 모드 (Command-line mode): ':'를 눌러 진입하며 저장(:w), 나가기(:q, :wq, :q!) 등을 실행하는 상태

## 실습에서 배운 점
- touch는 실행 즉시 파일이 생성되지만, vim은 내용을 작성하고 :w 또는 :wq로 명시적 저장을 해야 파일이 생성된다.
- 실수로 설정을 망쳤을 때는 무리하게 저장하지 말고 :q!를 통해 변경 사항을 버리고 안전하게 원본을 보존해야 한다.

## 막힌 것
입력 모드로 진입할 때 눌렀던 i가 본문에 타이핑되는 실수가 있었으나, 백스페이스로 정리 후 정상 작성 및 저장 완료함.
