## 찾아보고 알게 된 것

- **보안 관제에서 서버 grep 명령어를 사용하는 이유**:
    - 대규모 서버 환경에서는 하루 수십~수백만 줄 이상의 방대한 로그가 발생하여 눈으로 확인하기 불가능함
    - `grep`을 활용하면 오류(Error), 인증 실패(Failed password), 특정 비정상 IP 등 침해 사고 및 이상 징후 관련 행만 실시간으로 빠르게 필터링하여 대응 시간을 대폭 단축할 수 있음을 이해함
- **핵심 명령어 및 옵션 개념**:
    - **`cat`**: 파일의 전체 내용을 터미널 화면에 연속으로 출력하는 명령
    - **`grep` (기본)**: 파일 내에서 지정한 문자열 패턴이 포함된 라인 자체를 추출해 내용을 읽고자 할 때 사용
    - **`n` (number)**: 매칭된 줄 앞에 파일 내 줄 번호를 함께 표시해 문제 발생 지점의 파일 내 위치를 신속하게 특정할 때 유용함
    - **`c` (count)**: 단어의 단순 등장 횟수가 아닌, 해당 조건을 만족하는 '일치한 라인의 총 개수'를 집계하여 동일 유형의 이벤트 발생 빈도를 파악할 때 활용됨

## 막힌 것
