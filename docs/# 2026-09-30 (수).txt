- **Git/GitHub의 빈 폴더 관리 특성**: Git은 빈 디렉터리를 단독으로 추적하지 않으므로, 웹 UI에서 `agent_core/README.md`처럼 파일 경로를 함께 입력해 커밋해야 폴더가 유지된다는 점을 이해함

- **보안 수칙 준수**: 실습 코드 관리 시 민감 정보(`.env` 환경변수 파일, API Key, 토큰 등)가 퍼블릭 리포지토리에 노출되지 않도록 제외하고 업로드해야 함
