## 오늘 새로 쓴 명령

- `pwd`: 현재 위치한 디렉토리(폴더)의 전체 절대 경로를 출력한다.
- `ls`: 현재 디렉토리 안에 들어 있는 파일과 하위 폴더 목록을 보여준다.
- `ls -a`: 이름이 점(`.`)으로 시작하는 숨김 파일 및 상위/현재 폴더(`.`, `..`)까지 모두 포함해 출력한다.

## 찾아보고 알게 된 것

### 1. 보안 담당자와 개발자가 배우는 이유

- **보안 담당자가 리눅스 명령어를 쓰는 이유**:
    - 대부분의 서버 및 클라우드 인프라가 리눅스 환경으로 구동된다.
    - 서버는 보안과 자원 효율을 위해 GUI(그래픽)가 없어 터미널 명령어로만 제어해야 한다.
    - 대용량 로그 분석과 침해 사고 흔적 추적, 보안 자동화 스크립트 작성에 필수적이다.
- **개발자와 보안 담당자가 깃허브(GitHub)에 코드를 올리는 이유**:
    - 코드의 변경 이력(누가, 언제, 무엇을 바꿨는지)을 기록하고 문제가 생기면 이전 버전으로 되돌리기 위해서다.
    - 팀 단위 협업과 코드 리뷰(PR)를 진행하며, 배포 전 보안 취약점 점검을 자동화할 수 있다.

### 2. 핵심 용어 정리

- **터미널 (Terminal)**: 마우스 대신 키보드로 명령어를 입력하여 컴퓨터를 제어하고 결과를 텍스트로 확인하는 프로그램.
- **경로 (Path)**: 컴퓨터 시스템 내에서 파일이나 폴더의 위치를 나타내는 고유 주소 문자열.
- **깃배시 (Git Bash)**: 윈도우 기본 명령 체계와 다른 리눅스 명령어(Bash) 환경을 윈도우에서 동일하게 사용하고 Git을 다루기 위한 에뮬레이션 도구.

### 3. Git Bash 설치 시 유의사항

- `Select Start Menu Folder` 창에서 입력창이 비어 있을 경우 `Git`을 직접 입력해 진행한다.
- `Choosing the default editor` 단계에서는 권장 설정인 `Notepad(메모장)`를 기본 에디터로 선택한다.
- `Adjusting the name of the initial branch` 단계에서는 두 번째 옵션을 선택해 기본 브랜치 이름을 `main`으로 지정한다.

## 막힌 것

- 설치 도중 시작 메뉴 폴더 지정 창(`Select Start Menu Folder`)이 공란으로 비어 있어 다음 단계 진행 여부를 고민했으나, 직접 `Git`을 적어 넣고 해결했다.
- 에디터 선택(`Choosing the default editor`)과 기본 브랜치 이름 지정(`initial branch`) 단계에서 권장 옵션(`Notepad`, `main`)을 확인하고 적용했다.

## 다음에 확인할 것

- 절대경로(Root 기준)와 상대경로(현재 위치 기준)의 차이점 및 디렉토리 이동 명령어(`cd`).
- 오늘 기록한 `.md` 파일을 깃 저장소에 올리는 Git 기본 흐름(`add`, `commit`, `push`).

### 보너스 미션: 경로 표기 비교

- **Git Bash (`pwd` 실행 결과)**: `/c/Users/User`
- **윈도우 탐색기 주소창 경로**: `C:\Users\User`
- **표기 차이점**: 리눅스/Git Bash는 슬래시(`/`)를 구분자로 쓰고 드라이브 문자를 소문자 디렉토리 형태(`/c/`)로 표기하지만, 윈도우 탐색기는 드라이브 문자 뒤에 콜론과 역슬래시(`C:\`)를 사용한다.
