## 찾아보고 알게 된 것

- **보안 관제에서 패킷을 직접 분석하는 이유**:
    - 방화벽이나 IDS/IPS 로그는 단순 이벤트 알림에 불과하여 공격의 실체를 온전히 파악하기 어려움
    - 패킷 내부의 페이로드(데이터)를 직접 열어보아야 실제 악성 행위 여부, 정보 유출 데이터 내용, 비정상 트래픽 구조를 정확히 규명할 수 있음을 이해함
- **핵심 개념 이해**:
    - **패킷 (Packet)**: 네트워크를 통해 데이터를 주고받을 때 효율적인 전송을 위해 일정한 규격으로 쪼갠 기본 데이터 전송 단위 (헤더와 페이로드로 구성)
    - **Npcap**: Windows 환경에서 네트워크 카드를 통과하는 패킷을 가로채 사용자 애플리케이션(Wireshark)에 넘겨주는 핵심 캡처 드라이버/라이브러리
- **파이프(`|`)와 grep의 동작 메커니즘**:
    - `|` (파이프): 앞선 명령어의 출력 결과를 화면에 출력하지 않고 다음 명령어의 입력값으로 전달함
    - `grep`: 전달받은 텍스트 중 지정한 문자열(대소문자 구분)이 포함된 행만 추출하여 보여줌
