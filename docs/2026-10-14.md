# 2026-10-14 (수)

## 찾아본 것
서버에서 로그를 옮기고 백업하는 방법:
GUI 마우스가 없는 서버 환경(CLI)에서는 보안 담당자가 터미널 명령어를 사용해 증거 로그를 다룹니다. 원본 훼손을 방지하기 위해 cp 명령어로 사본을 만들어 백업하고, 분석 완료 후 보관 정책에 따라 mv 명령어로 아카이브 폴더로 이동하거나 날짜별로 파일명을 정돈합니다.

## 오늘 새로 쓴 명령
touch, cp, mv, rm, Tab 자동 완성

## 찾은 옵션
폴더째 복사 - -r / 덮어쓰기 전에 묻기 - -i / 폴더째 지우기 - -r

## mv 의 두 가지 쓰임
이름 바꾸기: 대상 위치에 새로운 '파일 이름'을 지정했을 때 (예: mv b.log c.log)
옮기기: 대상 위치에 '디렉터리(폴더)'를 지정했을 때 (예: mv c.log backup/)

## 막힌 것
실습용 파일을 생성할 때 줄바꿈 없이 입력되어 두 명령어가 합쳐졌으나, 파일 덮어쓰기(>)를 통해 원본 로그 내용을 다시 깔끔하게 복구하였다.

## 다음에 확인할 것
실무 환경에서는 중요한 포렌식 로그를 실수로 지우거나 덮어쓰지 않도록 -i 옵션을 기본 확인 습관으로 들이고 파일 쓰기 권한을 점검해야 한다.
